# 高频词与句式库

频次来自 621 篇文章、2,144,797 字正文的实测统计。数值是"每千字出现次数"。

## 一、口语连接词(密度 12–16 个/千字)

| 词 | 每千字 | 用法 |
| --- | --- | --- |
| 就是 | 2.49 | 解释、下定义、强调:"它就是解决这件事的" |
| 直接 | 1.53 | 推进动作:"我直接转发""直接上结论" |
| 但是 | 1.34 | 转折,比"然而"口语 |
| 然后 | 1.25 | 叙事推进,替代"接着""随后" |
| 真的 | 1.14 | 强调情绪:"真的有点离谱" |
| 其实 | 1.02 | 反转预期:"其实很多用户是懵逼的" |
| 大家 | 0.94 | 制造共同体:"大家应该都试过了吧" |
| 所以 | 0.92 | 口语因果,替代"因此" |
| 我觉得 | 0.57 | 表明个人判断 |
| 这玩意 | 0.21 | 降调、轻松化 |
| 说实话 | 0.19 | 引出真实判断 |
| 毕竟 | 0.19 | 给出理由 |
| 离谱 | 0.13 | 表达震惊 |
| 居然 | 0.09 | 制造反预期 |

语气词(每千字):了 11.6(含"了解/为了"等误计)、吧 0.56、呢 0.29、啊 0.27、哈 0.13、嘛 0.05。

## 二、开场句式(41% 的文章用时间锚开头)

| 开场类型 | 出现次数 | 模板 |
| --- | --- | --- |
| 今天 | 63 | 今天,我把… / 今天给大家分享… |
| 昨天 | 61 | 昨天呢,我在 X 上看到… |
| 最近 | 49 | 最近,国产模型也都起飞了 |
| 这两天 | 18 | 这两天,大家应该都用…了吧 |
| 上周 / 刚刚 / 前几天 | 15 / 14 / 11 | 具体时间点直接切入 |

其他开场:场景人物("这个正在威尼斯走红毯的小伙")、直接结论("XX,可能就是这次最大的受益者")、第二人称提问("你还记得…吗")。

## 三、过渡与节拍句式

- 推进:"说干就干。""OK,直接进正题。""那,让我们开始吧。"
- 换挡:"说到这,得先解释一下…""这事还没完。""但事情没这么简单。"
- 短段节拍(单独成段,5–15 字):"真的。""就这么简单。""离谱吧。""我人都傻了。"
- 收结论:"所以你会发现,真正的问题是…"

## 四、收尾句式

收尾段中位 15–17 字,常见形态:

- 判断:"这可能就是接下来一年最重要的事。"
- 行动:"想玩的话,今天就动手吧。"
- 情绪:"我到现在还记得那个晚上。"

禁止用"综上所述""总的来说""未来可期"这类总结句式收尾。

## 五、使用纪律

- 这些是节奏模板,不是可以照抄的句子。禁止整句搬运语料原文。
- 同一篇文章里,"就是/直接/其实"这类高频词不要每段都出现,密度控制在 12–16 个/千字。
- 严肃机构文把密度降到 4–8 个/千字,并去掉"这玩意/牛逼/离谱"这类词。
