# 量化基线与重测方法

## 一、语料基线(621 篇,2,144,797 字)

| 指标 | 全量 | 技术锚(74 篇) | 人文锚(41 篇) |
| --- | --- | --- | --- |
| 篇均正文 | 2770 字(中位) | 3414 | 3061 |
| 段落中位长度 | 30 字 | 32 字 | 31 字 |
| 段落平均长度 | 36.2 字 | 38.3 | 34.7 |
| 段落 p90 / p95 | 68 / 80 字 | 74 / 92 | 67 / 82 |
| 单段最长(中位) | 115 字 | 127 | 108 |
| >60 字段落占比 | 14% | 18% | 13% |
| ≤20 字段落占比 | 30% | 29% | 31% |
| 单段句数 | 1.1 | 1.13 | 1.06 |
| 句长 | 31.7 字 | 34.0 | 31.8 |
| 配图 | 6.0 张/千字 | 6.9 | 3.8 |
| 加粗 | 1.74 处/千字 | 2.26 | 1.68 |
| 数字 | 12.2 个/千字 | 15.9 | 13.8 |
| 口语标记 | 15.1 个/千字 | 14.4 | 13.3 |
| 结尾三段中位 | — | 17 字 | 15 字 |

反直觉结论:两个模式的**段落中位数几乎相同(32 vs 31)**,差异体现在长段占比(18% vs 13%)、
配图密度(1.8 倍)和结构密度(技术文每篇平均 5 个编号步骤,人文文为 0)。所以技术文靠"步骤长段",
而不是"通篇拉长"。

时间混淆已排除:2023–2026 年的段落中位长度分别为 32 / 30.5 / 28.5 / 31 字。

## 二、生成侧阈值(style_check.py 使用)

**硬规则(违反即 FAIL)**,区间取全语料 p05–p95 的保守外扩:

| 检查项 | 阈值 |
| --- | --- |
| 段落中位长度 | 20–45 字 |
| 单段句数 | 1.0–1.6 |
| 口语标记密度 | ≥7 个/千字 |
| 开场段长度 | ≤45 字 |
| 硬禁词 | 0 处(语料里出现 0 次的通稿词,共 9 个) |

**目标带(只提示 WARN,按模式区分)**:

| 检查项 | 技术文 | 人文文 |
| --- | --- | --- |
| >60 字段落占比 | 10%–30% | 5%–18% |
| 句长中位 | 25–39 字 | 21–33 字 |
| 收尾段长度 | 15–70 字 | 6–30 字 |
| 单段最长 | 建议 ≤300 字(引用/清单可放宽) | 同左 |
| 编号步骤数 | 教程类 ≥2,评测/观点类可 0 | 建议 0 |
| 包装词 | 少用:首先/其次/与此同时/随着/赋能/打造/闭环… | 同左 |

标定方法:用 622 篇真实文章自测,硬规则通过率 88.7%(真文章也有约一成会被提示,
属于风格边界样本)。段落中位数、句数、口语密度这类指标的语料分布很宽,
所以硬规则只拦明显跑偏的稿子,模式差异交给目标带提示。草稿短于 800 字时统计噪声大,
只做趋势参考。

## 二之二、人味分(0–100)

用来一眼判断"像不像人写的"。扣分线取自语料 p95,超出即扣分:

| 指标 | 语料中位 | 扣分线(p95) | 扣分 | 含义 |
| --- | --- | --- | --- | --- |
| 句首重复率 | 1.3% | >6% | -10 | 连续句子开头雷同 |
| 同构句连排 | 3 句 | >5 句 | -10 | 句长接近的句子排成一串 |
| 抽象名词密度 | 2.1 个/千字 | >6 个/千字 | -12 | 效率/体验/能力/闭环这类词堆叠 |
| 程度副词密度 | 1.4 个/千字 | >3.7 个/千字 | -10 | 非常/极其/显著/极大 |
| 被动句密度 | 0.69 个/千字 | >2.7 个/千字 | -6 | "被"字句 |
| 口语标记密度 | 14.7 个/千字 | <7 个/千字 | -15 | 见 rhetoric-bank |
| 硬禁词 | 0 | 命中即扣 | -20 | 语料里 0 次出现的通稿词 |
| 长段占比偏离模式 | — | 出目标带 | -8 | 见上表目标带 |
| 结构标记不符模式 | — | 技术文 <2 步 / 人文文 >0 步 | -5 | 见 SKILL.md |

**真实语料的人味分分布**:p10 = 81,中位 = 95,均值 = 90.5(n=622)。
因此交付线定在 **85**:低于 85 意味着这篇稿子比语料里 90% 的文章更像"AI 写的"。
参考:一段典型 AI 通稿能拿到 40 分左右,并同时在段落中位、口语密度、开场段上 FAIL。

## 二之三、原创性检查阈值

`scripts/overlap_check.py` 把草稿和语料都做归一化(去 markdown、去空白、全角标点转半角),
再按 12 字窗口比对:

| 最长连续重合 | 判定 |
| --- | --- |
| ≥30 字 | FAIL,必须重写该片段 |
| ≥18 字,或重合长度占草稿 >1% | WARN,人工确认是否需要改写 |
| 其他 | PASS |

自测:拿一篇语料原文当草稿跑,最长重合 6535 字(整篇命中)判 FAIL;
本 skill 自己写的范例文案为 0 重合判 PASS。语料路径用 `--corpus` 或环境变量 `CORPUS_DIR` 传入,
不写死在 skill 里。

## 三、重测方法

语料更新或换新样本时,按三步重测:

1. 把样本正文按篇存成 Markdown(一段一行,段落之间空行),放进语料目录的 `contents/`。
2. 用 `scripts/style_check.py` 的解析逻辑逐篇统计:段落长度、段内句数、句长、口语标记密度、
   长段占比、开场与收尾段长度。
3. 取这些指标在样本上的 p05–p95 分位,作为新的硬规则区间;模式差异用 p25–p75 设目标带。

原始语料里的标题清单仅用于对齐篇目,不参与风格统计。阈值改动后同步更新本文件与
SKILL.md 的自检表。

## 四、已知局限

- 技术/人文的锚定分组基于标题与结构规则,精度约七成;要冻结阈值需人工金标 100 篇校准。
- 段落长度受排版影响,同一篇文章在公众号和知乎的字数分布会有小幅差异。
- 语料覆盖 2023–2026 年,早期文章更长、更少图片,当前阈值偏向近期风格。

## 五、指标的定位(别用错)

把正文风格指标和实际点赞放一起算过(441 篇带赞数样本,同一年内排名控制偏差):

| 指标 | 与点赞的相关性 |
| --- | --- |
| 人味分 | 0.139 |
| 句首重复率 | 0.052 |
| 口语密度 | 0.015 |
| 长段占比 | -0.028 |
| 句长中位 | -0.037 |
| 段落中位 | -0.042 |
| 抽象名词密度 | -0.050 |

全部接近零。所以**人味分是交付质量指标**(读起来像不像人写的、节奏有没有崩),**不是传播预测指标**——它回答"这篇稿子能不能交",不回答"这篇会不会火"。

传播侧目前测得最清楚的信号不在正文里,而在标题与正文的一致性上(标题关键词覆盖率与点赞相关性 0.183),交接规则见 `handoff.md`。
