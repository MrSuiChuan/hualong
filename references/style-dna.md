# 共有文风 DNA(621 篇语料实测)

数据源:622 篇已发表的中文长文全文样本(其中 621 篇含有效正文),
测量方法与分位数据见 `metrics-baseline.md`。

## 二、节奏规律(核心)

**一段一句。** 全语料 1.1 句/段,几乎没有 3 句以上的段落。想讲三层意思,就写三段。

**长段之后必有短段。** 语料里 ≥60 字的段落,后面紧跟 ≤25 字短段的比例是 30%;连续短段的平均长度 1.7–1.8 段。这是文章"呼吸感"的来源,也是模型最容易写丢的部分。

真实的段落长度阶梯(取自语料,只保留字数):

```
35 / 9 / 23 / 35 / 36 / 46 / 5 / 49 / 48 / 9
```

短到 5 字、9 字的独立成段是刻意的节拍,不是排版事故。

**开场不铺垫。** 首段中位 25–32 字,直接抛现象、抛数字、抛场景,例如从"这几天,大家应该都用 XX 了吧"或"这个正在威尼斯走红毯的小伙"开始。禁止"随着…的快速发展"这类背景句。

**收尾收短。** 结尾三段中位 15–17 字,落在判断、行动或情绪上。语料里没有"综上所述""总结一下"式的结尾段。

## 三、语言层的三个习惯

**口语标记当连接词用。** 高频序:就是、直接、但是、然后、真的、其实、大家、所以、我觉得。语气词:了、吧、呢、啊、哈、嘛。这些词承担的是节奏和语气,删掉后句子会变成通稿腔。

**第一人称在场。** "我实测""我踩的坑""我第一反应是"是可信度的来源。技术文里它承担证据,人文文里它承担情绪。

**数字密度高。** 每千字 12.2 个数字,包括版本号、参数量、耗时、价格、播放量。数字必须真实;没有就写"大概""不到"这类模糊词,不编一个精确数字。

## 四、容易写错的地方

- 把 5–10 字的短段合并成一段:合并后节拍就没了,这是最典型的"AI 味"来源。
- 每个段落都写到 60–80 字:语料里这是长段,只占 14%。
- 用"首先/其次/最后"代替编号步骤和加粗小标题。
- 在人文文里堆形容词抒情;语料靠具体细节(时间、地点、动作、对话)承载情绪。
- 收尾写三段总结:语料收尾是一句话。
