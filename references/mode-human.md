# 人文文模式

适用:人物故事、行业观察、观点表达、经历复盘、时代与职业讨论。

## 一、结构模板

1. **场景或人物开场**(20–30 字):一个具体画面、一个时间点、一个人,不写背景。
2. **交代冲突**(3–6 段,每段 20–45 字):发生了什么、为什么反常、谁在为此焦虑。
3. **人物与细节**(4–8 段):具体动作、原话、数字、时间。用细节承载情绪,不用形容词。
4. **你的在场**(2–4 段):"我第一反应是…""我后来去查了一下…",让读者有同行的视角。
5. **转折**(2–4 段):一个反转、一个数据、一个不同意见,把前面的情绪推向更高一层。
6. **观点或情绪收束**(1–2 段,10–20 字):一句能被单独转发的话,不解释。

## 二、段落节奏

- 中位段长 28–33 字,>60 字的段落占比不超过 12%,单段不超过 80 字。
- 全篇靠短段推进:连续 2–4 个 15–35 字的段落是常态,情绪高点用 5–15 字的独立段。
- 长段只用于交代背景或引用他人观点,长段之后必须回到短段。
- 段内以 1 句为主;要用两个分句时用"然后""但是"这类口语连接,不用书面连接词。

## 三、情绪与细节的处理

- 情绪由细节承担:时间("凌晨 1 点")、动作("我循环了 7 遍")、原话("他说,我不干了")、数字("1.2 亿播放")。
- 可以写自己的反应与判断,但不写空洞抒情句,不发"我们这一代人啊"的感叹。
- 引用他人原话时保留口语(可以带错别字和语气词),不要改成书面语。
- 观点必须落在具体对象上:"这个功能在杀死朋友圈的分享欲"比"技术让人变得孤独"有效。

## 四、骨架示例(括号内为目标字数)

```
开场:人物或场景(25)
他是谁 / 发生了什么(30)
一个反常细节(20)
背景交代(60,全篇少数长段之一)
我第一反应(25)
细节 1:时间 + 动作(30)
细节 2:原话(35)
短段节拍(8)
细节 3:数字(30)
转折:真正的问题不是这个(35)
我的判断(45)
收尾:一句能被转发的话(15)
```

## 五、反例

- 通篇 60–80 字的长段:这是技术文的写法,人文文的呼吸会消失。
- 用形容词堆情绪:"无比震撼""令人心碎"——改成具体动作和原话。
- 编造"我有个朋友"来推进:素材门不允许;没有真实人物就写公开事件与自己的观察。
- 结尾升华到时代与人类:语料收尾是短句,不写三段排比。
